# kintone-lite-suite

kintone の設定比較、プレビュー反映、設計書・ER図出力、レコード運用を、用途ごとの単機能 JavaScript として提供するリポジトリです。

## 収録ツール

`tools/` 直下の次のファイルが配布用 bundle です。

- `差分比較.js`
- `プレビュー反映.js`
- `フィールド追加.js`
- `kintoneJS取得.js`
- `設定取得.js`
- `設計書作成.js`
- `ER図.js`
- `プロセス実行.js`
- `kintoneレコード取得.js`
- `CSV出力.js`
- `データ品質チェック.js`

正規ソースは `tools/統合ツール/src/` にあります。配布用 bundle と `tools/単機能スクリプト棚卸し.md` はビルド生成物なので、直接編集しないでください。

## セットアップと検証

Node.js 20 以上、npm 10 以上を使用します。

```bash
npm ci
npm run setup
npm run check
```

`npm run check` はブラウザストレージ検査、通常・strict 型検査、Vitest、ビルドを実行します。ビルド後に Git 差分が残る場合は生成物の更新漏れです。

Playwright の比較・出力ハーネスは `tools/test-harness/README.md` を参照してください。

全11ツールの型検査・単体テスト・ビルド・画面／出力検証は `npm run test:all` でまとめて実行できます（Chrome が必要）。

アプリ名検索は100件ずつ追加取得でき、アプリURLからゲストスペースも判別します。複数アプリのIDはカンマ・空白区切りで貼り付けられ、選択中の文字列を置き換えます。設定取得で一部が失敗した場合は、保存後も失敗件数と再取得の案内を表示します。

検索方法を「アプリコード」に切り替えると完全一致で検索でき、名前・コード検索はスペースIDでも絞れます。候補にはコード・所属スペース・更新日時・更新者を表示します。レコード管理では、一覧の絞り込みと並び順をクエリに反映し、添付フィールドを名前から選択できます。テーブル内の添付にも対応しています。詳しい使い方と根拠となる公式APIは [APIレスポンスを利用する補助機能](docs/api-response-improvements.md) を参照してください。

CSV取込には、全対象アプリのフィールド設定に照らした事前検査と先頭行のプレビューがあります。実行時にも全対象を再検査してから追加します。ステータス更新では、同名アクションを遷移元ごとに選択し、実行条件・次の作業者・実行者の設定を確認して対象クエリを入力できます。

「重複・未入力を検査」では、名前から1〜5項目を選び、組み合わせの重複と未入力を調べられます。該当レコードへのリンクと全結果CSVを出力します。「CSV取込ひな形を作成」では、取込可能な列と必須・選択肢などの入力ガイドをアプリごとのZIPフォルダに保存します。使い方は [データ検査とCSVひな形](docs/record-quality-and-template.md) を参照してください。

```bash
npm run test:output-layouts
npm run test:diff-multi-dom
npm run test:diff-compare
npm run test:er-compare
```

## 安全上の注意

反映・追加・更新を行うツールは kintone の設定やデータを変更します。対象環境、App ID、処理方向を確認し、必要なバックアップを取得してから実行してください。

独立した Excel、FreeBoard、スケジュール、データ加工ツールは、それぞれ別リポジトリで管理します。
