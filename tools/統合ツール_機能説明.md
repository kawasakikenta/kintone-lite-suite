# 統合ツール 機能説明

対象: `統合ツール.js`

## 概要

このツールは、kintone アプリ設定の比較、プレビュー反映、設計書出力、設定取得、影響分析、レコード運用、可視化、API 試験を 1 つにまとめた統合運用ツールです。

> SQL 実行（`kintoneSQL.js`）は統合ツールには含まれません。`tools/standalone/kintoneSQL.js` の単独ブックマークレットとして利用してください。

主な用途は以下です。

- 開発環境と本番環境の設定差分を確認する
- 比較元の設定を比較先のプレビュー環境へ反映する
- フィールドや JS/CSS 設定を個別に移送する
- 設計書や差分レポートを出力する
- 複数アプリの設定をまとめて保存する
- フィールド参照・通知・権限・レイアウトを横断的に分析する
- レコード運用や可視化作業をまとめて行う

## 基本概念

- 比較元: コピー元、参照元となるアプリ
- 比較先: 差分確認先、反映先となるアプリ
- プレビュー: アプリ設定の未デプロイ領域
- バンドル: 各種設定をまとめて取得した JSON データ
- セクション: アプリ設定の比較単位

比較対象セクションは主に以下です。

- アプリ設定
- フィールド設定
- レイアウト設定
- フォーム設定
- ビュー設定
- レポート設定
- プロセス管理
- プラグイン
- JS/CSS 設定
- アクション設定
- アプリ権限
- フィールド権限
- レコード権限
- 通知設定
- レコード条件通知
- リマインダー通知
- カテゴリ設定

## 共通設定

画面上部の共通設定は、ほぼ全タブで利用します。

### 接続先設定

- 比較元アプリ ID / ゲスト ID / プレビュー指定
- 比較先アプリ ID / ゲスト ID / プレビュー指定
- 比較元を現在アプリに設定
- 比較元の内容を比較先へコピー
- 比較元と比較先の入れ替え

### 環境プロファイル

- 比較元 / 比較先の組み合わせを名前付きで保存
- 開発、検証、本番などの環境切替を簡略化

### ルックアップ参照先アプリ ID 変換

- フィールド反映時に参照先アプリ ID を置換
- 環境ごとにアプリ ID が異なる場合の移送を補助

### 作業履歴

- 作業状態（接続先・選択状態など）をセッション内メモリへ手動保存・復元
- 履歴の個別削除 / 全削除
- ブラウザ再読み込みで消去されます（ブラウザストレージは使用しません）

### 共通データ取得 / クイック実行

- 比較元 / 比較先の共通データを先読み
- 差分比較から反映プラン確認までを連続実行

## タブ別機能

### 1. 差分比較

差分比較タブは 3 つのサブタブに分かれます。

#### 非フィールド差分の検出精度

フィールド以外のセクションも、エンティティ単位で安定して差分を検出します。

- **ドメイン識別子マッチング**: アプリ権限はエンティティ（type:code）、フィールド権限・レコード権限のエンティティ配列も対象エンティティ、一般通知は宛先エンティティ、レコード条件通知・リマインダー通知はタイトル、遷移アクションは name|from|to の組み合わせで左右をマッチング。並び替えは added/removed の嵐ではなく moved 行（低重要度）に集約され、個別の変更は「どのエンティティの何が変わったか」単位で出力されます
- **純粋並び替え検出**: 中身が同一で並びだけ違う配列（レイアウト行など）は moved 行のみで報告
- **moved 統合（LCS）**: 並び替えと追加/削除が混在する配列でも、同一内容が別位置に現れた added/removed ペアを moved 1 行（移動位置「N番目 → M番目」付き）に統合
- **表記ゆれ・空値ゆれの降格**: `"100"` ⇄ `100`、`"true"` ⇄ `true` など実質同値の差分は「表記のみ」、空文字 / null / 空配列 / 空オブジェクト同士の差分は「空値ゆれ」としてバッジ表示し、重要度を低に降格
- **改名検出**: フィールドコード変更やビュー / ステータス / 通知などのエンティティ改名を added/removed のペアから推定し「改名候補」として表示。プロセス管理のステータス改名は遷移アクションの from/to 参照カスケードを自動吸収し、改名 1 行に集約
- **重要度の精緻化**: プロセス管理の無効化・プラグイン削除/無効化・JS/CSS ファイル削除は high、プロセス管理の有効化・プラグイン追加/有効化は medium と判定
- **影響範囲の拡張**: フィールド削除・改名時の影響範囲にフィールド権限・レコード権限の参照を含むほか、ステータス削除・改名行には参照している遷移アクション（遷移元/遷移先）を影響として表示

#### 比較条件

- 比較対象セクションの選択
- 無視キーの設定
- よく使う無視プリセットの適用
- セクション別正規化プリセットの適用
- 無視キーの保存 / 読込
- 比較元 / 比較先バンドルの読込、解除、保存
- **差分比較の実行 → HTML レポート即出力**: 「差分比較を実行」を押すと、比較完了と同時に差分 HTML レポートをダウンロードします（出力ボタンを別途押す必要はありません）。「全比較先を順に比較」でも比較先ごとに HTML を自動保存します。JSON / Excel / バンドル / パッチ出力は廃止
- HTML レポートは「差分一覧」「フィールド単位」の 2 タブ構成（サマリー / 比較対象設定タブは廃止）。レポート内の「詳細オプション」で、出力前と同じ無視キー・順序無視などの条件を後から選択して表示を絞り込み可能
- 「範囲」で全件 / 表示中を選び直して HTML を再出力することも可能

#### HTML レポートの機能

差分 HTML レポートは、単体で完結する自己完結型ページです（外部 CDN 依存なし）。

- **差分一覧タブ**: セクション別に差分行を表示。種別（追加 / 削除 / 変更 / 移動 / 同一）で絞り込み、文字単位ハイライトで変更箇所を強調
- **素のJSONで比較表示**: フィールド単位の集約をやめ、各設定プロパティを整形前の JSON 値でそのまま左右比較するモード。生の設定値を直接見比べたいときに使用
- **フィールド単位タブ**: フィールドコード単位で、比較元 / 比較先の設定を kintone の設定ダイアログ風スナップショットで左右に並べ、値が異なる項目に差分色を付与。関連レコード一覧設定・ルックアップ設定・テーブル内の項目は、日本語ラベル付きの key-value 表で差分行を赤（比較元のみ）/緑（比較先のみ）/黄（変更）に色分けし、変更値は文字単位でハイライト
- **確認済み管理**: 各差分行の「確認」チェックで確認済みをマークし、サイドバーの「確認済みを隠す」で残作業だけに絞り込み。確認済み件数はサマリーに表示
- **コピー / エクスポート**: 行ごとに設定パス・値（JSON）をワンクリックコピー。表示中の差分を CSV 保存 / Markdown 表としてクリップボードにコピー
- **キーボード操作**: `J` / `K`（または「前へ / 次へ」）で差分行を順に移動、`Ctrl/⌘+F` で検索フォーカス、`Esc` で検索クリア
- ライト / ダークテーマ切替、セクションへのジャンプナビ、印刷プレビュー対応

#### セクション別ビュー（フィールド以外の差分を専用可視化）

非フィールドセクション向けに、カテゴリ別タブと各セクション専用の可視化を提供します。

- カテゴリタブ: フィールド / レイアウト / ビュー・グラフ / プロセス・アクション / 通知 / 権限 / JS・CSS・プラグイン / アプリ設定（数字キー 1〜8 で切替）
- **フィールド**: フィールドコード単位で集約し、重要度の高い順に表示。ラベル・型バッジ・重要度ドット付きで、フィールド定義の追加/削除はタイプ / ラベル / 必須 / 選択肢などの要約で表示
- **権限**: エンティティ × 操作のマトリクス（許可↑ / 縮小↓ を色分け）。フィールド権限は NONE / READ / READ_WRITE の昇降を矢印で表示
- **プロセス**: ステータス遷移を SVG フロー図で表示（追加=緑/破線、削除=赤/破線、不変=灰）。ステータス一覧・アクション一覧を別表で併記
- **通知**: ルールカード（条件・トリガー・タイミング・宛先エンティティ）
- **ビュー・グラフ**: 表示項目・絞込条件・ソートをカード表示。変更ビューは変更詳細を折りたたみで列挙
- **レイアウト**: 比較元 / 比較先の配置を並べたグリッドビュー（新規=緑、削除=赤、GROUP は紫枠）
- **JS/CSS・プラグイン**: ファイル一覧（desktop / mobile × JS / CSS）とプラグインのバージョン差分
- **アプリ設定**: 変更があるキーのみを抽出した key-value 表（appSettings / appInfo / formSettings / categories）
- ヘッダーに比較元/比較先アプリ名を表示
- Markdown コピー / ファイル保存 / 印刷プレビュー対応

#### 履歴・監視

- 比較スナップショット履歴の保存と復元
- 履歴の一括削除
- 複数比較先への一括差分比較

### 2. プレビュー反映

比較元の設定を比較先プレビューへ反映するタブです。

- 差分を元に反映対象セクションを選択
- セクション単位の反映
- 高重要度セクションの自動選択
- セクション別の差分件数 / 重要度確認
- ノード単位の反映
- ノード検索、絞り込み、全選択、表示中のみ選択 / 解除、Undo / Redo
- 反映対象と最新プランのサマリ表示
- バックアップ自動保存
- エラー時中断
- 反映後デプロイ
- 反映プラン確認（反映の方向〔比較元 → 比較先プレビュー〕とアプリ名を明示、削除を含む場合は赤帯で件数を警告）
- プラン確認キャンセル時も結果表示を維持（Esc・×・背景クリックでも安全にキャンセル）
- プラン確認モーダルから直接反映する場合は同内容の確認を重複表示しない（最終確認は必ず実施）
- 最終確認の重さはリスクに比例（注意点なし: チェックのみ / 注意点あり: キーワード入力 / 高リスク: 比較先アプリID入力）
- 比較先プレビューのバックアップ
- プレビューへの反映
- デプロイのみ実行
- パッチ JSON を直接読込 / 編集して反映

単機能版（`プレビュー反映.js`）では、上記に加えて次の操作補助があります。

- 実行結果をセクション単位で記録し、「失敗・未実行だけ選択」で再実行対象をワンクリックで選び直し（エラー中断時の未実行セクションも含む）
- 反映エラーのログに対処ヒントを併記（権限不足 / アプリID誤り / ルックアップ参照先 / フィールド未反映 / 通信エラーなどの典型パターン）
- 高リスク実行の追加確認（比較先アプリID入力）時に、高リスクと判定した理由を明示
- 実行後に「比較先の設定画面を開く」から運用環境への反映（デプロイ）操作へ直接移動

### 3. フィールド追加

フィールド追加タブは 3 つのサブタブに分かれます。

#### JSON編集

- `properties` 形式のフィールド JSON を直接編集
- 比較先プレビューへ反映
- 同一コード上書き
- 更新後デプロイ
- 比較先の現在フィールド読み込み
- 「検証のみ」ボタンで反映前に code/label/type の整合性チェックと統計サマリ（合計／書込可／システム／サブテーブル／ルックアップ／計算／タイプ別内訳）を表示
- JSON 整形
- JSON ファイル読込 / 保存

#### 比較元から追加

- 比較元アプリのフィールド一覧を取得
- 選択したフィールドを JSON にマージ

#### 一括整備

- フィールドコードへのプレフィックス一括追加 / 削除
- 未使用候補の調査は「分析」タブの影響分析サブタブに集約

### 4. JS/CSS 設定

JS/CSS 設定タブは 2 つのサブタブに分かれます。

#### 設定編集

- 比較元アプリの JS/CSS 設定取得
- 比較先アプリの現在値読込（反映前の現状確認）
- JSON 表示 / 編集
- JSON 出力
- JSON ファイル読込
- 比較先プレビューへ反映
- 反映後デプロイ指定

#### 一括ダウンロード

- 比較先側スペース内の全アプリ JS/CSS 添付を一括 ZIP 化

### 5. ER図

ER図タブは 2 つのサブタブに分かれます。

#### ER図

- 比較元アプリを起点に関連アプリを探索
- ルックアップ / 関連レコードを辿って ER 図生成
- スペース ID 指定でスペース内全アプリを起点に追加（スペース所属アプリは二重枠で表示）
- レイアウト指定
- 表示密度指定
- 探索深さ指定
- サブテーブル項目の含有切替
- HTML 保存

#### 依存関係

- フィールド間の依存関係マップ生成
- 計算式、条件、プロセスなどの参照関係を可視化

### 6. プロセス図

- プロセス管理設定から Mermaid フロー図を生成
- Mermaid ソースの表示／コピー／.mmd ファイル保存／SVG 保存
- フロー図プレビュー
- 統計サマリ（ステータス・アクション・始点・終端・分岐数）と未定義参照などの警告表示
- 状態遷移シミュレーション（アクション履歴・一手戻し対応）

### 7. 設計書

設計書タブは 2 つのサブタブに分かれます。

#### 設計書出力

- 設計書 JSON 出力
- 設計書 Markdown 出力
- Markdown コピー
- 設計書 Excel 出力
- 設定JSON読込（任意）: 「設定一括取得」で保存したJSON（複数アプリの `apps` 配列にも対応）を読み込むと、kintoneへ接続せずそのJSONの内容だけから設計書（JSON / Markdown / Excel いずれも）を生成できる。設定一括取得タブの結果一覧から「設計書へ」ボタンで直接読み込むことも可能。複数アプリ一括Excel出力（ZIP）でも、対応する設定JSONが読み込まれているアプリはAPI取得をスキップする。

#### 差分レポート

- 比較元と比較先の設計書差分を Markdown レポートとして出力

### 8. 設定一括取得

設定一括取得タブは 2 つのサブタブに分かれます。

#### 一括取得

- 複数アプリ ID をまとめて指定
- アプリ名検索から追加
- スペース ID 指定でスペース内全アプリを一括追加
- 比較元 / 比較先 / 現在アプリの追加
- 取得対象セクションの選択
- JSON 出力
- ZIP 出力
- 結果サマリにアプリ名と全体集計（OK / NG 合計）を表示

#### テンプレート

- 比較元アプリ設定のテンプレート保存
- 保存済みテンプレートの読込
- テンプレート削除

### 9. 分析

分析タブは 6 つのサブタブに分かれます。影響調査・依存確認・通知/権限/レイアウトの確認をまとめて行えます。

#### ダッシュボード

- 影響分析ダッシュボードの表示
- 参照数上位フィールド / 依存が多いフィールド / 未使用候補のサマリ
- 設定ボリュームと取得失敗セクションの確認
- 各サブタブへのジャンプ導線

#### 影響分析

- フィールドコード単位の参照箇所横断検索
- ビュー、計算式、プロセス管理などからの参照集計
- コード / ラベル / 種別での絞り込み
- 未使用フィールドのみの抽出
- CSV 出力

#### 通知設定

- 一般通知 / レコード条件通知 / リマインダー通知の一覧
- 宛先エンティティと条件の確認
- CSV 出力

#### 権限

- アプリ権限 / フィールド権限 / レコード権限の一覧
- エンティティ単位の権限集計
- エンティティ / フィールド / 条件での検索
- CSV 出力

#### レイアウト

- フォームレイアウトのプレビュー表示
- 比較元 / 比較先を並べて表示する差分比較モード

#### 依存グラフ

- フィールド間の依存関係グラフ表示
- 入出力の参照関係を可視化
- 孤立ノードの非表示切替
- ノードクリックによる詳細表示

### 10. レコード管理

レコード管理タブは 5 つのサブタブに分かれます。

#### ステータス更新

- 一覧条件に一致するレコードのプロセス管理を一括実行

#### 添付DL

- 一覧条件に一致する添付ファイルを ZIP で一括ダウンロード

#### CSV

- 一覧条件に一致するレコードの CSV エクスポート
- CSV ファイルからの一括インポート

#### バックアップ

- 一覧条件に合致するレコードを CSV・添付ファイル・コメント込みで ZIP バックアップ
- 必要に応じてアプリ設定 JSON も同梱

#### アプリ間コピー

- 比較元アプリのレコードを比較先アプリへ一括コピー

### 11. APIテスター

- kintone API の GET / POST / PUT / DELETE を直接実行
- パスまたは URL を指定
- リクエスト Body を JSON で入力
- レスポンスを画面表示
- プリセットはカテゴリ別（取得 / 更新 preview）に整理。アプリ情報・設定・フィールド・レイアウト・ビュー・プロセス管理・デプロイ状態・レコード・コメント等
- 「JSON整形」で Body を検証＋整形
- 実行メタ表示（経過時間 / レスポンス形状 / サイズ / ステータス）と、レスポンスのコピー / JSON 保存
- 実行履歴に時刻を表示、履歴の JSON エクスポート
- 画面内 Ctrl/Cmd + Enter で実行

## 推奨利用フロー

典型的な使い方は以下です。

1. 比較元 / 比較先を設定する
2. 必要なら環境プロファイルを適用する
3. 差分比較で設定差分を確認する
4. 反映プランを確認する
5. 比較先プレビューへ反映する
6. 必要に応じてデプロイする
7. 設計書や差分レポートを出力して記録を残す

## 注意事項

- 反映系処理は比較先プレビューまたは本番データへ影響します
- 全レコード削除、CSV インポート、アプリ間コピーは実データ変更を伴います
- 反映前にバックアップを取得する運用を推奨します
- ルックアップ、添付ファイル、プロセス関連の移送は環境差異の影響を受けやすいです
- プラグイン設定はプラグイン本体の配布や個別設定内容までは含まれない場合があります
