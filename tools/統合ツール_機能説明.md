# 統合ツール 機能説明

対象: `統合ツール.js`

## 概要

このツールは、kintone アプリ設定の比較、プレビュー反映、設計書出力、設定取得、影響分析、レコード運用、可視化、API 試験を 1 つにまとめた統合運用ツールです。

> SQL 実行（`kintoneSQL.js`）は統合ツールには含まれません。`tools/standalone/kintoneSQL.js` の単独ブックマークレットとして利用してください。

主な用途は以下です。

- 開発環境と本番環境の設定差分を確認する
- 比較元の設定を比較先のプレビュー環境へ反映する
- フィールドや JS/CSS 設定を個別に移送する
- 設計書や差分レポートを出力する
- 複数アプリの設定をまとめて保存する
- フィールド参照・通知・権限・レイアウトを横断的に分析する
- レコード運用や可視化作業をまとめて行う

## 基本概念

- 比較元: コピー元、参照元となるアプリ
- 比較先: 差分確認先、反映先となるアプリ
- プレビュー: アプリ設定の未デプロイ領域
- バンドル: 各種設定をまとめて取得した JSON データ
- セクション: アプリ設定の比較単位

比較対象セクションは主に以下です。

- アプリ設定
- フィールド設定
- レイアウト設定
- フォーム設定
- ビュー設定
- レポート設定
- プロセス管理
- プラグイン
- JS/CSS 設定
- アクション設定
- アプリ権限
- フィールド権限
- レコード権限
- 通知設定
- レコード条件通知
- リマインダー通知
- カテゴリ設定

## 共通設定

画面上部の共通設定は、ほぼ全タブで利用します。

### 接続先設定

- 比較元アプリ ID / ゲスト ID / プレビュー指定
- 比較先アプリ ID / ゲスト ID / プレビュー指定
- 比較元を現在アプリに設定
- 比較元の内容を比較先へコピー
- 比較元と比較先の入れ替え

### 環境プロファイル

- 比較元 / 比較先の組み合わせを名前付きで保存
- 開発、検証、本番などの環境切替を簡略化

### ルックアップ参照先アプリ ID 変換

- フィールド反映時に参照先アプリ ID を置換
- 環境ごとにアプリ ID が異なる場合の移送を補助

### 操作ログ

- 実行した主要操作をローカル保存
- CSV 出力
- ログ全削除

### 共通データ取得 / クイック実行

- 比較元 / 比較先の共通データを先読み
- 差分比較から反映プラン確認までを連続実行

## タブ別機能

### 1. 差分比較

差分比較タブは 3 つのサブタブに分かれます。

#### 比較条件

- 比較対象セクションの選択
- 無視キーの設定
- よく使う無視プリセットの適用
- セクション別正規化プリセットの適用
- 無視キーの保存 / 読込
- 比較元 / 比較先バンドルの読込、解除、保存
- 差分比較の実行
- 差分 JSON / HTML / Excel / パッチ JSON の保存
- 定期差分監視の設定

#### 結果整理

- セクション / 種別 / 重要度でのフィルタ
- 出力対象の切替
- 選択差分の管理
- お気に入り表示
- 比較ビュー検索
- 文字単位差分表示
- 同一項目の表示切替
- ライト / ダークテーマ切替
- 差分件数しきい値警告
- おすすめ無視キー候補の表示
- 表示モード切替（**📋 行一覧** ⇄ **🗂 セクション別ビュー**、V キーでトグル）

#### セクション別ビュー（フィールド以外の差分を専用可視化）

非フィールドセクション向けに、カテゴリ別タブと各セクション専用の可視化を提供します。

- カテゴリタブ: フィールド / レイアウト / ビュー・グラフ / プロセス・アクション / 通知 / 権限 / JS・CSS・プラグイン / アプリ設定（数字キー 1〜8 で切替）
- **権限**: エンティティ × 操作のマトリクス（許可↑ / 縮小↓ を色分け）。フィールド権限は NONE / READ / READ_WRITE の昇降を矢印で表示
- **プロセス**: ステータス遷移を SVG フロー図で表示（追加=緑/破線、削除=赤/破線、不変=灰）。ステータス一覧・アクション一覧を別表で併記
- **通知**: ルールカード（条件・トリガー・タイミング・宛先エンティティ）
- **ビュー・グラフ**: 表示項目・絞込条件・ソートをカード表示。変更ビューは変更詳細を折りたたみで列挙
- **レイアウト**: 比較元 / 比較先の配置を並べたグリッドビュー（新規=緑、削除=赤、GROUP は紫枠）
- **JS/CSS・プラグイン**: ファイル一覧（desktop / mobile × JS / CSS）とプラグインのバージョン差分
- **アプリ設定**: 変更があるキーのみを抽出した key-value 表（appSettings / appInfo / formSettings / categories）
- ヘッダーに比較元/比較先アプリ名を表示
- Markdown コピー / ファイル保存 / 印刷プレビュー対応

#### 履歴・監視

- 比較スナップショット履歴の保存と復元
- 履歴の一括削除
- 複数比較先への一括差分比較

### 2. プレビュー反映

比較元の設定を比較先プレビューへ反映するタブです。

- 差分を元に反映対象セクションを選択
- セクション単位の反映
- 高重要度セクションの自動選択
- セクション別の差分件数 / 重要度確認
- ノード単位の反映
- ノード検索、絞り込み、全選択、表示中のみ選択 / 解除、Undo / Redo
- 反映対象と最新プランのサマリ表示
- バックアップ自動保存
- エラー時中断
- 反映後デプロイ
- 反映プラン確認
- プラン確認キャンセル時も結果表示を維持
- 比較先プレビューのバックアップ
- プレビューへの反映
- デプロイのみ実行
- パッチ JSON を直接読込 / 編集して反映

### 3. フィールド追加

フィールド追加タブは 3 つのサブタブに分かれます。

#### JSON編集

- `properties` 形式のフィールド JSON を直接編集
- 比較先プレビューへ反映
- 同一コード上書き
- 更新後デプロイ
- 比較先の現在フィールド読み込み
- JSON 整形
- JSON ファイル読込 / 保存

#### 比較元から追加

- 比較元アプリのフィールド一覧を取得
- 選択したフィールドを JSON にマージ

#### 一括整備

- フィールドコードへのプレフィックス一括追加 / 削除
- 未使用候補の調査は「分析」タブの影響分析サブタブに集約

### 4. JS/CSS 設定

JS/CSS 設定タブは 2 つのサブタブに分かれます。

#### 設定編集

- 比較元アプリの JS/CSS 設定取得
- JSON 表示 / 編集
- JSON 出力
- JSON ファイル読込
- 比較先プレビューへ反映
- 反映後デプロイ指定

#### 一括ダウンロード

- 比較先側スペース内の全アプリ JS/CSS 添付を一括 ZIP 化

### 5. ER図

ER図タブは 2 つのサブタブに分かれます。

#### ER図

- 比較元アプリを起点に関連アプリを探索
- ルックアップ / 関連レコードを辿って ER 図生成
- スペース ID 指定でスペース内全アプリを起点に追加（スペース所属アプリは二重枠で表示）
- レイアウト指定
- 表示密度指定
- 探索深さ指定
- サブテーブル項目の含有切替
- HTML 保存

#### 依存関係

- フィールド間の依存関係マップ生成
- 計算式、条件、プロセスなどの参照関係を可視化

### 6. プロセス図

- プロセス管理設定から Mermaid フロー図を生成
- Mermaid ソースの表示
- フロー図プレビュー
- 状態遷移シミュレーション

### 7. 設計書

設計書タブは 2 つのサブタブに分かれます。

#### 設計書出力

- 設計書 JSON 出力
- 設計書 Markdown 出力
- Markdown コピー
- 設計書 Excel 出力

#### 差分レポート

- 比較元と比較先の設計書差分を Markdown レポートとして出力

### 8. 設定一括取得

設定一括取得タブは 2 つのサブタブに分かれます。

#### 一括取得

- 複数アプリ ID をまとめて指定
- アプリ名検索から追加
- スペース ID 指定でスペース内全アプリを一括追加
- 比較元 / 比較先 / 現在アプリの追加
- 取得対象セクションの選択
- JSON 出力
- ZIP 出力

#### テンプレート

- 比較元アプリ設定のテンプレート保存
- 保存済みテンプレートの読込
- テンプレート削除

### 9. 分析

分析タブは 6 つのサブタブに分かれます。影響調査・依存確認・通知/権限/レイアウトの確認をまとめて行えます。

#### ダッシュボード

- 影響分析ダッシュボードの表示
- 参照数上位フィールド / 依存が多いフィールド / 未使用候補のサマリ
- 設定ボリュームと取得失敗セクションの確認
- 各サブタブへのジャンプ導線

#### 影響分析

- フィールドコード単位の参照箇所横断検索
- ビュー、計算式、プロセス管理などからの参照集計
- コード / ラベル / 種別での絞り込み
- 未使用フィールドのみの抽出
- CSV 出力

#### 通知設定

- 一般通知 / レコード条件通知 / リマインダー通知の一覧
- 宛先エンティティと条件の確認
- CSV 出力

#### 権限

- アプリ権限 / フィールド権限 / レコード権限の一覧
- エンティティ単位の権限集計
- エンティティ / フィールド / 条件での検索
- CSV 出力

#### レイアウト

- フォームレイアウトのプレビュー表示
- 比較元 / 比較先を並べて表示する差分比較モード

#### 依存グラフ

- フィールド間の依存関係グラフ表示
- 入出力の参照関係を可視化
- 孤立ノードの非表示切替
- ノードクリックによる詳細表示

### 10. レコード管理

レコード管理タブは 5 つのサブタブに分かれます。

#### ステータス更新

- 一覧条件に一致するレコードのプロセス管理を一括実行

#### 添付DL

- 一覧条件に一致する添付ファイルを ZIP で一括ダウンロード

#### CSV

- 一覧条件に一致するレコードの CSV エクスポート
- CSV ファイルからの一括インポート

#### バックアップ

- 一覧条件に合致するレコードを CSV・添付ファイル・コメント込みで ZIP バックアップ
- 必要に応じてアプリ設定 JSON も同梱

#### アプリ間コピー

- 比較元アプリのレコードを比較先アプリへ一括コピー

### 11. APIテスター

- kintone API の GET / POST / PUT / DELETE を直接実行
- パスまたは URL を指定
- リクエスト Body を JSON で入力
- レスポンスを画面表示

## 推奨利用フロー

典型的な使い方は以下です。

1. 比較元 / 比較先を設定する
2. 必要なら環境プロファイルを適用する
3. 差分比較で設定差分を確認する
4. 反映プランを確認する
5. 比較先プレビューへ反映する
6. 必要に応じてデプロイする
7. 設計書や差分レポートを出力して記録を残す

## 注意事項

- 反映系処理は比較先プレビューまたは本番データへ影響します
- 全レコード削除、CSV インポート、アプリ間コピーは実データ変更を伴います
- 反映前にバックアップを取得する運用を推奨します
- ルックアップ、添付ファイル、プロセス関連の移送は環境差異の影響を受けやすいです
- プラグイン設定はプラグイン本体の配布や個別設定内容までは含まれない場合があります
